A Vampire Survivors inspired game built in Python with Pygame.

The game currently offers:
-2 weapons
-6 enemies
-health and level system
-mini radar

Controls:
[WASD] to move
[Space] or [Enter] to start
[1], [2]. [3] to select upgrades
[R] to restart
[Esc] to exit

How to play:
Download shape-survivors.exe and run or enter "pip install pygame-ce", "cd downloads/shape-survivors" (or where you downloaded the file) and python shape-survivors.py" in cmd
