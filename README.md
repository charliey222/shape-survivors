Shape Survivors is a Vampire Survivors inspired roguelike game built using Python and Pygame. 
_Clanker summary:_
Players navigate an open grid while battling waves of geometric enemies, collecting experience points to level up, and unlocking powerful weapon upgrades. The game features custom stat-scaling mechanisms, dynamic upgrade pooling, a JSON-based save and load progression system, and immersive visual effects like alpha-blended transparency.

The is my first "big" coding project outside of game macros. I had a lot of fun writing the code (except the rendering).

The game currently offers:
-3 characters
-5 weapons
-6 enemies
-health and level system
-mini radar

Controls:
[WASD] (the arrow keys and numpad work too!) to move
[Space] or [Enter] to start
[1], [2], [3] (or just use WASD and space/enter) to select upgrades
[R] to restart
[Esc] to exit
[Tab] to pause

How to play:
Download shape-survivors.exe and run

OR enter "pip install pygame-ce" (you can skip this if you have pygame already installed) and "cd downloads/shape-survivors" (or where you downloaded the file) and python shape-survivors.py" in cmd if you don't have an interpreter (if you do you can just run it from there)
